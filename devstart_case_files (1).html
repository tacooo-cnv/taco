HISTORY FILES

機密歷史：C++ 的演進

EARLY ERA

機器碼與組合語言

早期電腦更接近直接操作硬體指令，後來逐步出現更容易閱讀與編寫的組合語言。

1970s

高階語言興起

C 語言成為系統程式設計的重要基礎，影響後續許多語言的設計。

1979

Bjarne Stroustrup 展開研發

最初的設計稱為「C with Classes」，逐步加入物件導向能力。

1983

正式命名為 C++

「++」象徵對 C 語言的延伸與進步。

1998

成為 ISO 國際標準

C++ 標準化後，語言規範進一步制度化並持續演進。

TERMINAL NOTES
程式通常會依照流程一步一步執行。C++ 中多數敘述以 ; 結尾，而 // 後面的內容會被當成註解。
編譯提醒：實際競程環境是否支援 <bits/stdc++.h>，取決於編譯器與平台；教學與競賽常見 GCC 環境通常可使用。
TOOLS & MEMORY
1. 資料型態與記憶體空間

int 常見為 4 bytes；32 位元有號整數常見範圍為 −2,147,483,648 到 2,147,483,647。float / double 用於浮點數，char 儲存單一字元，bool 表示真偽，string 儲存文字。

整數溢位：當整數運算超出型態可表示範圍時，結果不再可信。實務上應選擇合適的型態並留意運算範圍。
2. 字元與字串操作
string s = "Hello World";
cout << s.size();
cout << s.empty();

string fullName;
getline(cin, fullName);

其中 getline() 可以讀取包含空白的整行文字。

3. 算術演練：BMI 計算程式
#include <iostream>
using namespace std;

int main() {
    double weight, height, bmi;
    cin >> weight;
    cin >> height;
    bmi = weight / (height * height);
    cout << bmi << endl;
    return 0;
}

這個範例示範輸入、變數、四則運算與輸出等基本流程。

🟡 RE

🟠 TLE
Time Limit Exceeded
超過時間限制，可能需要改善演算法。
🟤 MLE
Memory Limit Exceeded
記憶體使用量超出限制。
